Futures Tick Value and Point Value Explained

Before you can read a futures chart with any confidence, you need to know what a single price move is worth in dollars. This guide walks through tick size, tick value and point value, with the math written out so you can check it yourself.

Level: Beginner Read time: about 7 minutes Covers: ES, NQ, MES, MNQ

Why this matters before anything else

Index futures quote prices in index points, but your account balance moves in dollars. The bridge between the two is the contract specification. Every futures contract defines three numbers: the tick size, the tick value, and the point value. If you do not know these, a move on the chart can look small while the dollar result is much larger, or the reverse.

This page is education only. It does not tell you what to trade, when to trade, or what result to expect. It only explains how the arithmetic works.

Point value: what one full index point is worth

A point value is the dollar amount of one full point of price movement, for one contract. Each index future has a fixed point value set by the exchange. A one point move in the S&P 500 E-mini (ES) is worth $50 per contract. A one point move in the Nasdaq-100 E-mini (NQ) is worth $20 per contract.

The micro versions are sized at one tenth of their full-size parents. The Micro E-mini S&P 500 (MES) carries a point value of $5. The Micro E-mini Nasdaq-100 (MNQ) carries a point value of $2.

Tick size: the smallest price step

A tick is the minimum price increment the contract can move. For ES, NQ, MES and MNQ the tick size is 0.25 index points. Prices can only land on quarter points, so the market steps in increments of 0.25 and never in between.

Tick value: the dollar value of one tick

Tick value is the dollar amount of one minimum price step for one contract. It is the tick size multiplied by the point value:

Tick value = Tick size × Point value Tick size is measured in index points. Point value is dollars per full point.

Run the four contracts through that formula and you get the table below. The point value and tick size are the only inputs; everything else follows from them.

Working the math by hand

Once you have the tick value, you can translate any price move into dollars. Two steps cover it: count the ticks, then multiply by the tick value. Counting ticks is simple division: the points moved divided by 0.25.

Dollar move = (Points moved ÷ 0.25) × Tick value Same answer as Points moved × Point value.

Example one: ES

Suppose the ES price moves from one level to a level 3 points higher. That is 3 ÷ 0.25 = 12 ticks. At $12.50 per tick, 12 ticks is $150 for one contract. Check: 3 points × $50 = $150. Same result.

Example two: MNQ

Suppose the MNQ price moves 10 points. That is 10 ÷ 0.25 = 40 ticks. At $0.50 per tick, 40 ticks is $20 for one contract. Check: 10 points × $2 = $20.

Example three: contract count

Multiply by size. Two NQ contracts moving 5 points is 5 × $20 = $100 per contract, so $200 total. Position size scales every dollar figure in a straight line, which is why sizing is covered separately in the margin guide linked below.

A quick way to remember it

Points tell you the move

The chart shows index points. That is the language of price.

Dollars tell you the stake

Your account lives in dollars. Point value converts one to the other.

Ticks tell you the steps

Every price change is a count of 0.25 steps. Tick value prices each step.

Micros are the same math

MES and MNQ use the same tick size. Only the dollar value per tick changes.

Things the formula does not include

  • Commissions and fees. Your broker and the exchange charge per contract. These reduce any result and are not in the tick math above.
  • Slippage. A fast market can fill you at a price away from the one you saw. Tick math assumes a clean fill, which is not guaranteed.
  • Contract changes. Specifications are set by the exchange and can change. Check the current contract page.
  • Margin. Holding a position requires margin, which is a separate concept from tick value. See the margin guide.
